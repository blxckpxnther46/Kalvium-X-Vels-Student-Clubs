## Core Focus Areas

The clubs are built around four main actions:

- 2D & 3D Club: Create visual art, UI designs, animations, and game assets.
- Social Media Club: Tell stories, edit videos, record podcasts, and manage media.
- Abstract Strategies Club: Think critically through strategy games, business models, and negotiation.
- Debate & Public Speaking Club: Communicate clearly through debates, pitches, and keynote talks.
