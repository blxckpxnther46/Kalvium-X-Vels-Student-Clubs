# Project Repositories & Build Logs

Every completed project sprint must be systematically documented to build a permanent repository of student innovation.

---

## 📁 Repository Standards

- **Code & Design Repositories**: Upload software projects, 3D Blender files, and Figma design tokens to official university GitHub / Figma organizations.
- **Build Logs (`BUILD_LOG.md`)**: Each project repository must include a build log summarizing:
  1. Team members and individual role contributions.
  2. Tools and frameworks utilized.
  3. Key technical/creative challenges encountered and solutions.
  4. Final screenshots, video demos, or live URL links.
