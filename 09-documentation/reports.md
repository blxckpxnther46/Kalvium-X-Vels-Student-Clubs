# Monthly Retrospective Reports

Following each Showcase Day, Club Presidents submit a **Cycle Retrospective Report** to the Operations Team and Mentors.

---

## 📊 Retrospective Template Structure

```markdown
# [Club Name] — Cycle [N] Retrospective

## 1. Executive Summary
Brief overview of monthly sprint performance and key achievements.

## 2. Sprint Deliverables Completed
- Deliverable A: [Link/Status]
- Deliverable B: [Link/Status]

## 3. Key Metrics
- Total Active Members: [Count]
- Average Session Attendance: [%]
- Showcase Day Participation: [Count]

## 4. What Went Well & Areas for Improvement
- Successes: ...
- Bottlenecks: ...

## 5. Action Items for Next Cycle
- [ ] Task 1
- [ ] Task 2
```
